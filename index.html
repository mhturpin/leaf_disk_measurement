Image Scanning Program Explanation

About the highlighted image:

  • The black outlines indicate what portions of the image were identified as leaf disks.
  • The solid black squares in the corners indicate which row the leaf disk got grouped into. All leaf disks in the same row have the same markings.
  • The necrotic pixels have been turned red, and the live pixels have been turned green.
  • The white circle is what the program determined to be the best fit circle for the line between live and necrotic tissue. This circle is only relevant to the slope score.

What the algorithm does:

  1. Extract the pixel data from the uploaded image.
  2. Find all the blobs of connected dark pixels.
  3. Determine which blobs are leaf disks based on if the dimensions of each blob form roughly a square and if the blob has approximately the expected number of dark pixels to be a circle.
  4. Calculate the necrotic gradient scores:
    • Count how many necrotic pixels are at each distance from the center of the leaf disk.
    • Isolate just the counts representing the gradient portion.
    • Do a linear regression on those counts.
    • Calculate the area under the line. This is the score.
  5. Calculate the slope score:
    • Find the best fit circles for the necrotic boundaries. This is the most common edge pixel distance from the center of the disk.
    • Calculate the necrotic width by subtracting the best fit circle radius from the average leaf disk radius.
  6. Display the highlighted image.
