Process Leaf Disk Image

To use this program, upload an image that is 3" wide with leaf disks that are 5/8". The program uses these values to determine what is a leaf disk and what isn't. There is more information about how it works at the bottom of the page. If you run into any issues, such the circle being in the wrong location, leaf disks not being identified, or rows not grouping properly, please let me know. Thank you!

About the highlighted image:

  • The black outlines indicate what portions of the image were identified as leaf disks.
  • The solid black squares in the corners indicate which row the leaf disk got grouped into. All leaf disks in the same row have the same markings.
  • The necrotic pixels have been tinted red, and the live pixels have been tinted green.
  • The white circle is what the program determined to be the best fit circle for the line between live and necrotic tissue.
  • The pink pixels are what the program determined to be the edge between live an necrotic tissue.

What the algorithm does:

  1. Extract the pixel data from the uploaded image.
  2. Find all the connected light/dark edges in the images using my implementation of the Canny edge detector.
  3. Determine what is a leaf disk based on if the maximum left/right/top/bottom of the connected edge form roughly a square and are approximately the right diameter.
  4. Calculate the average diameter of the leaf disks in pixels. This will be used later and should be more accurate than using the width of the scanned image as the reference.
  5. Find the necrotic boundary for each leaf disk. Use the edge detector, but with the value as high if r > g and for the background, otherwise low. Since the r > g filter can be noisy, set any "live" pixels to "necrotic" if the pixels around them are mostly necrotic before doing the edge detection.
  6. Find the best fit circles for the necrotic boundaries. The best fit circle is the most common edge pixel distance from the center of the disk.
  7. Calculate the necrotic width.
  8. Display the highlighted image.
